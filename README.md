# Citizen Tab (citizentab)

Mod **serveur** NeoForge 21.1.215 / Minecraft 1.21.1 / Java 21.
La liste Tab n'affiche plus les pseudos : chaque joueur apparaît avec son **recensement**, tenu par **Citizen Economy** :

`Aldric Valmont • 32 ans • Forgeron`

Un joueur pas encore recensé apparaît en « Citoyen non recensé ». Rien à installer chez les joueurs.

- Recensement des joueurs : `/recensement` (Citizen Economy)
- Administration : `/recensement admin`, menu d'administration de Citizen Economy ou panneau web du Conseil royal
- La ligne se met à jour toute seule en quelques secondes après chaque changement.

Nécessite Citizen Economy (avec le recensement) sur le serveur. Avec Citizen Noms : le Tab affiche le recensement, le nom de Citizen Noms reste dans le chat et au-dessus de la tête.
